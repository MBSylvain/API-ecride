# FAQ EcoRide


## Problèmes courants

### Impossible de se connecter
- Vérifiez que votre email et mot de passe sont corrects.
- Si vous avez oublié votre mot de passe, utilisez la fonction "Mot de passe oublié" sur la page de connexion.
- Assurez-vous que votre compte est activé (vérifiez l’email d’activation).
- Si le problème persiste, contactez le support.

### Email de notification non reçu
- Vérifiez le dossier spam ou courrier indésirable de votre boîte mail.
- Assurez-vous que l’adresse email renseignée dans votre profil est correcte.
- Vérifiez la configuration SMTP dans le fichier `Utils/Mailer.php` (pour les administrateurs).
- Consultez la documentation technique : [docs/documentation_technique.md](documentation_technique.md)

### Erreur lors de la réservation
- Vérifiez que toutes les informations requises sont saisies (trajet, nombre de places, etc.).
- Assurez-vous que le trajet est disponible et que vous avez suffisamment de crédits.
- Consultez les messages d’erreur affichés pour plus de détails.
- Si le problème persiste, contactez le support.

### Problème d’affichage ou de navigation
- Essayez de vider le cache de votre navigateur.
- Vérifiez que vous utilisez une version récente de votre navigateur.
- Si le problème concerne l’application mobile, vérifiez les mises à jour disponibles.
- Consultez la documentation utilisateur : [docs/manuel_utilisateur.md](manuel_utilisateur.md)

## Solutions

- Pour tout problème technique, consultez la documentation technique et la FAQ.
- Pour les problèmes de compte, utilisez la fonction de réinitialisation du mot de passe.
- Pour les notifications, vérifiez la configuration SMTP et les paramètres de votre profil.
- Pour les bugs ou suggestions, contactez le support.
